# fight

這是一個雙人決鬥網頁遊戲。

## 遊戲玩法

- 玩家 1: A/D 移動，W 雙連跳，S 普攻，G 瞬間移動（最多 3 次，每 3 秒恢復 1 次），Y 勾索，F 重擊，U 幻影連斬，Q 防禦
- 玩家 1 重擊：空中按 F，快速追蹤敵方下墜重捶；傷害依觸發後的下落距離增加，短距離至少造成少量傷害，長距離最高 56 點，命中會擊飛，未命中會留下大範圍龜裂，冷卻 6 秒。連線與機器人模式中，玩家 1 使用 A/D、W、S、G、Y、F、U、Q。
- 玩家 1 吸血：按 E 啟動，持續 4 秒，冷卻 7 秒；期間普攻、重擊與幻影連斬命中敵人時，恢復該次實際傷害的 40% 生命值。
- 重擊從樹木或屋頂平台落下時會撞破平台，背景會顯示斷裂樹木或塌陷屋頂，角色會繼續墜落到地面；平台破壞狀態會維持到本局結束，下一局開始時恢復。
- 對戰中會隨機發生山崩地裂：地面先劇烈晃動，接著裂成兩半；每次下墜掉入裂縫都會受到傷害並被向上擊飛。每次地震都會新增一條永久裂縫，裂縫會持續到本局結束，隨時間經過越來越多，下一局開始時恢復。
- 單機玩家 2: 左／右箭頭移動，上箭頭雙連跳，下箭頭普攻，句點鍵波動拳（向 16 個方向密集發射子彈），5 治療，/ 隱分身，7 隕石衝擊，0 防禦
- 與機器人決鬥：可選擇新手、普通、困難或魔王難度，並分別自訂玩家與電腦使用的角色；選角後會倒數並立即開始。
- 遊戲會使用瀏覽器內建音效播放決鬥 BGM、倒數、普攻、技能、命中、防禦、治療、大招及勝利音效；首次按下開始後才啟動聲音，符合瀏覽器自動播放限制。
- 主選單提供音量降低、提高及靜音按鍵，音量設定會保存在目前瀏覽器中。

## 玩法說明

- 每位玩家有 100 點生命值
- 戰場向左右延伸；兩位玩家距離較遠時鏡頭會縮小以同時顯示雙方，靠近後平滑恢復原始大小
- 場景中的樹枝與房屋屋頂可作為落腳平台，跳躍即可登上
- 雙方各可連跳兩次，落地後重置跳躍次數
- 普攻、波動拳或勾索命中玩家時會造成擊退並震動畫面（1.5 倍震動）
- 玩家 1 瞬間移動一段距離，每 3 秒恢復 1 次充能；玩家 2 波動拳向 16 個方向密集發射子彈，冷卻時間為 5 秒
- 玩家 1 勾索命中敵人後會將其拉近，冷卻 5 秒；玩家 2 隱分身會召出三個可迷惑並抵擋攻擊的分身，冷卻 7 秒
- 玩家 2 隕石衝擊（單機按 7、連線按 F）在敵人上方召喚三顆隕石，命中造成傷害並擊飛；未命中的隕石會在地面留下隕石坑，任何玩家落入都會受傷並彈飛，冷卻 15 秒
- 防禦啟動後 0.3 秒內免疫傷害與擊退，冷卻 4 秒；連線模式雙方皆按 Q，單機玩家 1 按 Q、玩家 2 按 0
- 當只剩一位玩家存活時，遊戲結束
- 每局戰鬥開始後限時 90 秒；時間到仍未分出勝負則本局平手，比分不變並可重新開始。
- 採三戰兩勝制，先贏兩局者獲勝；平手局不計分並重新進行，畫布上方血條中間會顯示 BO3 比分

## 執行方式

打開 `index.html` 即可在瀏覽器中遊玩。

## 兩支手機連線對戰

1. 將本資料夾內全部檔案上傳至原本 GitHub 儲存庫的網站發布目錄（覆蓋 index.html、script.js、style.css，新增 multiplayer.js、peerjs.min.js 及授權檔）。
2. 等 GitHub Pages 發布完成，兩支手機開啟同一個 HTTPS 網址並重新整理。
3. 在首頁查看技能教學，選擇「單人模式」或「連線模式」。
4. 連線模式下，房主按「建立房間」並分享 8 碼房號；另一位玩家輸入房號加入。連線成功後，房主同步目前畫面狀態；加入者收到有效狀態後會顯示相同的主選單或戰鬥畫面，正式對戰畫面會顯示角色選擇。
5. 系統隨機決定房主或加入者先選角；一方選擇玩家 1 或玩家 2 角色後，另一方會自動使用剩餘角色。畫面中央倒數「3、2、1、Fight!」後開始對局。
6. 玩家 1 使用 A/D 移動、W 跳躍、S 普攻、G 瞬移、Y 勾索及 U 大招。玩家 2 使用相同的按鍵位置：A/D 移動、W 跳躍、S 普攻、G 波動拳、Y 隱分身、U 治療、F 隕石衝擊；觸控操作也會依角色顯示技能按鈕。單機模式玩家 2 使用方向鍵、句點、5 及 / 操作原有技能，隕石衝擊改按 7。
7. 對局結束後，房主可按「重新開始」再戰；按「返回主選單」可離開對局或連線。

### 連線限制

- 需要網際網路連上公共 PeerJS 配對服務；不是離線區域網路模式。
- 目前採用 PeerJS 1.5.5 預設連線服務，未配置專用 TURN 中繼伺服器。某些電信網路、防火牆或 NAT 環境可能無法直連；可先讓兩支手機使用同一個 Wi-Fi。若要涵蓋此類網路，需另行配置 TURN 服務。
- 手機請保持網頁在前景；切換背景會停止對戰，避免角色失控，回來後重新建立房間。
- 房間只接受一名對手；房號只分享給要一起玩的朋友。
- 房主以每秒 60 步計算遊戲、約每秒 20 次傳送戰況；客端會插值平滑角色、投射物、分身與主要技能特效的位置。同步時只傳送有限數量的主要特效，不傳送大量粒子與殘影，避免大招造成封包過大或連線佇列堆積。客端不自行判定傷害。

### 驗證狀態

已通過 JavaScript 語法檢查與雙端模擬測試：建立房號、加入及開局、角色控制隔離、移動和波動拳同步、放開按鍵、再戰及斷線清理。
尚未以兩支實體手機或真實 WebRTC 網路完成測試；此資料夾為待部署版本，並未修改線上網站。
