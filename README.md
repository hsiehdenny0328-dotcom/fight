# fight

這是一個支援本機雙人與線上房間對戰的網頁遊戲。

## 遊戲玩法

- 玩家 1: A/D 移動，W 雙連跳，S 普攻，Q 瞬間移動，E 勾索
- 玩家 2: 左／右箭頭移動，上箭頭雙連跳，下箭頭普攻，句點鍵波動拳（向八個方向發射子彈），/ 隱分身

## 玩法說明

- 每位玩家有 100 點生命值
- 雙方各可連跳兩次，落地後重置跳躍次數
- 普攻、波動拳或勾索命中玩家時會造成擊退並震動畫面
- 玩家 1 瞬間移動一段距離，玩家 2 波動拳向八個方向發射子彈，兩者冷卻時間皆為 3 秒
- 玩家 1 勾索命中敵人後會將其拉近，冷卻 5 秒；玩家 2 隱分身會召出三個可迷惑並抵擋攻擊的分身，冷卻 7 秒
- 當只剩一位玩家存活時，遊戲結束

## 線上對戰

- 房主按「建立線上房間」，將顯示的 6 位數房號分享給對手
- 使用「複製房號」複製號碼，或用「分享邀請連結」傳送可直接加入房間的連結
- 對手開啟邀請連結後會自動加入房間，不必再手動輸入房號
- 對手輸入房號並加入後，遊戲會自動開始
- 房主使用玩家 1 操作，加入房間的玩家使用玩家 2 操作
- 每個房間為兩人 1 對 1；若要再玩一場，請建立新房間
- 按空白鍵可在對戰結束後重新開始；按「離開房間」可返回本機模式

## 執行方式

線上房間需要先啟動遊戲伺服器。在 Windows 上雙擊專案資料夾中的 `start-server.bat`，再於瀏覽器開啟：

```text
http://localhost:8000
```

同一個區域網路的玩家可透過房主電腦的區域網路 IP 位址與連接埠 `8000` 開啟遊戲。跨網路對戰則需將伺服器部署到可公開連線的主機，並讓遊戲頁面與 API 由同一個來源提供。

伺服器視窗需保持開啟才能進行線上對戰。不啟動伺服器時，仍可直接開啟 `index.html` 遊玩本機雙人模式。

## 部署到網際網路

專案已提供 Render Blueprint 設定（`render.yaml`），可部署遊戲頁面與線上房間伺服器：

1. 將專案變更推送到 GitHub。
2. 登入 Render，選擇 **New + → Blueprint**，連結此 GitHub 專案。
3. Render 讀取 `render.yaml` 後建立 `fight-game` 服務；等待部署完成。
4. 開啟 Render 提供的 `https://...onrender.com` 網址，建立房間並分享遊戲內的邀請連結。

免費服務閒置時可能休眠，首次開啟需要等待服務喚醒；房間狀態存在伺服器記憶體中，伺服器重啟或休眠後，舊房間會失效，重新建立房間即可。
